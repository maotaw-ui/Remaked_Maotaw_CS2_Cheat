## 🔄 Offset Update System

The project uses **[CS2 Dumper by a2x](https://github.com/a2x/cs2-dumper)** to generate game offsets.

### How it works

1. Launch Counter-Strike 2.
2. Run the included CS2 Dumper executable.
3. Allow the dumper to generate its output files.
4. The application reads the generated offsets from the configured output folder.

This makes updating offsets easier without manually replacing them every time.

> **Note:** Compatibility is not guaranteed after every CS2 update. Updates to the game or dumper may require additional changes to the application.
